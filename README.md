## 关于「Agent 评测」这一节

这一节不只讲方法，也讲结果——包括一次**推翻自己结论**的自查：

1. **设计**：把「对」拆成正确行为（GT）、判定规则（Oracle）、允许变化、禁止行为四段；题目与判法物理隔离，判据出处逐条校验。
2. **第一轮（Detect 五步）**：12 个原子案例 + 27 份测试数据，五观察面判定，结果 12/12 Pass、红线 5/5、有效评分率 97.8%，结论 CONDITIONAL_GO。
3. **自查**：绿灯之下发现置信度分数从未被算法算出、运行包混入 31 处评测答案，判定旧结论失效——失效链是「评审要求 GT 可判定 → 把算法输出写死进 GT → 运行时读到同一份文件的字面量 → 12/12 全 Pass」。
4. **第二轮（评测台）**：按四平面合同重建隔离并加可复跑检测器（泄漏 31 → 0），重跑 14 题 / 47 场景 / 232 条机器断言 + 52 条人工判据，跑出 21 条规格差距 + 3 条红线违规；并量化出「模型参与率对结果的影响面 ≈ 4%」。
